# Hermes Skills

Community-contributed skills for [Hermes Agent](https://github.com/NousResearch/hermes).

## Skills

| Skill | Description |
|---|---|
| [terminal-ascii-box-cjk-alignment](terminal-ascii-box-cjk-alignment/) | CJK-safe ASCII art: boxes, tables, flowcharts with proper right-edge alignment |

## Install a Skill

```bash
hermes skills install https://raw.githubusercontent.com/Andy365-365/hermes-skills/main/<skill-name>/SKILL.md
```

## Add Your Skill

1. Create a directory named `<skill-name>` under this repo
2. Add a `SKILL.md` file with YAML frontmatter
3. Optionally add `scripts/`, `templates/`, `references/` subdirectories
4. Push a PR or commit directly

See [Hermes Agent skill docs](https://hermes-agent.nousresearch.com/docs) for the SKILL.md format.
